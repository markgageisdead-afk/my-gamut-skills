# San Antonio Cultural Event Lead Scout

A Gamut skill for researching San Antonio-area event opportunities and identifying sponsor-branded photo activation prospects.

## Contents

- [`SKILL.md`](./SKILL.md) — operating instructions and output format
- [`SKILL.mdd`](./SKILL.mdd) — compact skill metadata and activation guidance

## Intended use

Run this skill for a defined date range and geography. It returns publicly sourced event leads, qualification tags, a transparent score, and draft outreach. It does not send outreach or collect private contact data.

## Recommended prompt

> Find San Antonio events in the next 90 days with vendors or sponsors and no photo activation mentioned. Include source URLs, public organizer contacts, qualification tags, evidence, and draft sponsor-activation outreach.
